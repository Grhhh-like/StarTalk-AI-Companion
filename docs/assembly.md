# 星语 StarTalk · 焊接装配与调试指南

## 所需工具

| 工具 | 说明 |
|---|---|
| 恒温烙铁 | 建议 350°C，配 0.8mm 烙铁头 |
| 焊锡丝 | 0.5mm 含铅/无铅均可 |
| 助焊剂/松香 | 焊接 QFN、LGA 类小封装 |
| 镊子 | 贴片器件夹取 |
| 万用表 | 短路检测、电压测量 |
| 热风枪（可选） | 返修/吹焊模组 |

## 焊接顺序（由低到高）

1. **电源部分优先**：TP4057、ME6211、Type-C 座、阻容 → 上电测 3.3V；
2. **主控模组**：ESP32-S3-WROOM-1（注意天线方向）；
3. **外围芯片**：INMP441、MAX98357A、SHT40；
4. **被动与接口**：喇叭座、电池座、按键、LED；
5. **LCD 屏**：最后焊接（排线脆弱，注意对位）。

## 通电检查清单

- [ ] Type-C 插入后 TP4057 充电指示灯亮（红充/绿满）；
- [ ] 万用表测 ME6211 输出 ≈ 3.3V；
- [ ] 无短路、无器件异常发热；
- [ ] 串口可识别（CH340/CP2102），`idf.py flash` 烧录成功。

## 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 无法烧录 | BOOT 引脚/驱动 | 按住 BOOT 上电，检查驱动 |
| 唤醒无反应 | 麦克风焊接/极性 | 检查 I2S0 引脚与焊接 |
| 无声音 | 功放/喇叭 | 测 MAX98357A 供电与 I2S1 波形 |
| 温湿度乱码 | I2C 上拉/地址 | 检查 4.7K 上拉与 0x44 地址 |
| 屏幕白屏 | SPI 时序/背光 | 检查 5V/3.3V 电平与 BL 引脚 |

## 调试建议

- 首次调试用 `idf.py monitor` 观察日志，分级 `ESP_LOGx` 输出；
- 用 `menuconfig` 逐项填入 WiFi/API 后重新编译；
- 建议先用 USB 供电调试，再切电池供电验证低功耗。
