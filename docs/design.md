# 星语 StarTalk · 硬件设计文档

## 1. 设计目标

- 桌面级 AI 语音交互伴侣，成本 ≤ 150 元，初学者可复刻；
- 离线唤醒 + 在线大模型对话 + 本地 TTS 播放 + 表情屏反馈；
- 全开源：嘉立创EDA 工程 + 固件 + 外壳。

## 2. 系统框图

```
        ┌─────────────────────────────────────────────┐
        │                 电源系统                      │
        │  Type-C ── TP4057 ── 3.7V锂电 ── ME6211 ── 3.3V
        └─────────────────────────────────────────────┘
                    │
┌───────────────────┼───────────────────────────────────┐
│                   │  ESP32-S3-WROOM-1 (N8R8)          │
│   I2S0  ── INMP441 数字麦克风（唤醒词输入）              │
│   I2S1  ── MAX98357A 功放 ── 8Ω 3W 喇叭（TTS输出）      │
│   SPI   ── GC9A01 1.28" 240×240 圆屏（表情）           │
│   I2C   ── SHT40 温湿度传感器                          │
│   GPIO  ── 触摸按键 / LED 状态灯                       │
└───────────────────────────────────────────────────────┘
```

## 3. 器件选型说明

### 3.1 主控 ESP32-S3-WROOM-1 (N8R8)

| 参数 | 值 | 说明 |
|---|---|---|
| 内核 | Xtensa LX7 双核 | 240 MHz |
| 存储 | 8MB Flash + 8MB PSRAM | 足够跑 ESP-SR 与 HTTPS 缓冲 |
| WiFi | 2.4G 802.11 b/g/n | 连接 LLM API |
| AI | SIMD 指令加速 | 神经网络唤醒词推理 |

选型理由：ESP32-S3 是当前开源 AI 硬件事实标准，资料多、外设全、支持 ESP-SR 离线唤醒，且 ESP-IDF 生态成熟。8MB PSRAM 保证 HTTPS 大响应与音频缓冲不卡顿。

### 3.2 麦克风 INMP441

- MEMS 数字 I2S 麦克风，24-bit，信噪比 61dB；
- 直接输出 PDM/I2S，无需运放/ADC 前级，抗干扰好；
- 用于 ESP-SR 唤醒词与本地命令词识别（不上云）。

### 3.3 功放 MAX98357A

- 3.2W D 类功放，I2S 数字输入，免输出滤波；
- 直接驱动 8Ω/3W 喇叭，音量 I2C/引脚可调；
- TTS 音频流经 I2S 直接播放，延迟低。

### 3.4 屏幕 GC9A01 1.28 英寸

- 240×240 圆形 LCD，SPI 接口，16-bit 色；
- 用于表情/状态/波形显示，库支持成熟（TFT_eSPI / lvgl）。

### 3.5 温湿度 SHT40

- I2C 接口，精度 ±1.8%RH / ±0.2°C；
- 支持语音查询环境数据，增加实用性。

### 3.6 电源

| 器件 | 作用 | 关键参数 |
|---|---|---|
| TP4057 | 锂电线性充电 | 500mA，Type-C 5V 输入 |
| ME6211 | 3.3V LDO | 500mA 输出，低 dropout |
| 锂电池 | 供电 | 3.7V 800–1200mAh 锂聚合物 |

## 4. 引脚分配（GPIO）

| 外设 | 信号 | GPIO |
|---|---|---|
| I2S0 录音 | SCK/WS/SD | 4 / 5 / 6 |
| I2S1 播放 | BCLK/WS/DIN | 15 / 16 / 17 |
| SPI LCD | SCK/MOSI/DC/CS/RST/BL | 12 / 11 / 10 / 9 / 8 / 7 |
| I2C | SDA/SCL | 2 / 3 |
| 按键 | KEY | 0 (BOOT) |
| 状态灯 | LED | 18 |

> 具体以嘉立创EDA工程为准。

## 5. PCB 设计要点

- 2 层板，尺寸约 45mm × 45mm，板厚 1.6mm；
- 天线区域净空：ESP32-S3 模块天线侧禁铺铜/禁走线；
- 音频走线短且远离电源，麦克风远离喇叭磁路；
- 电池接口 + 防反接；Type-C CC 电阻使能 5V；
- 3.3V 退耦电容 100nF × N + 10uF 就近放置。

## 6. 成本估算

| 项目 | 成本 |
|---|---|
| PCB 打样（免费额度） | ~0 元 |
| 元器件（BOM） | ~80–110 元 |
| 喇叭/电池/外壳 | ~20–40 元 |
| **合计** | **约 100–150 元** |
